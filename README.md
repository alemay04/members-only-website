# First Release ---- 11/24/2026
The first version of this Odin Project is released, but still need a lot of improving. There three types of users for this website :

## Non-users :
- Can see every message with title
- Cannot authors of timestamp of the publication
- Can click on the member? button to join the club with a secret password

## Users :
- Can see every message with title
- Can see authors of timestamp of the publication
- Can click on the admin? button to become admin with a secret password

## Admin :
- Same functionnalities as a user
- Can delete post with the delete button

## Improvings
- Could add functionnalities like updating post
- Need validation for message posting or login (isnt implemented even if stated on UI)
